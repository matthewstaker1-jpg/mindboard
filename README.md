# Mindboard

Blindfold chess trainer. See `BUILD_PLAN.md` for the spec and `CLAUDE.md` for working rules.

Node lives in `~/.local/node/bin` (added to PATH in `~/.zprofile`).

```bash
npm run dev    # http://localhost:5173 — currently the Board gallery
npm test       # unit tests
npm run build  # typecheck + production PWA build
```
